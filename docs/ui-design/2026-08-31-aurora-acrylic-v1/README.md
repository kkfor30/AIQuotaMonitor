## 视觉约束

### 浅色

- 背景使用 `#EAF2F7` 至 `#F7FAFC` 的低饱和冰蓝银白层次。
- 主文字使用深墨蓝 `#142536`，避免浅灰文字落在透明面板上。
- 面板采用克制磨砂、银白内高光和冰蓝细边，不允许整页高强度发光。
- 余额主值使用冰蓝，不使用黄色或暖金承担金额语义。
- 缓存或 stale 提示使用低饱和蓝灰，不使用黄色制造告警误解。

### 深色

- 页面基底以 `#0C2B3A` 为中心，不使用近黑背景。
- 面板使用 `#123747` 至 `#1A4554` 的中深蓝灰层级。
- 主文字为高对比白色；时间、说明、单位和图例统一使用清晰浅蓝灰 `#B8CBD6`。
- 只允许悬浮外壳、选中态和重点图表使用较强冰蓝光；普通卡片只保留细边和轻微折射。
- 禁止大面积暖金边缘光和高反差霓虹。

### 共同语义

- 剩余额度 `80–100%` 使用绿色、`20–80%` 使用蓝色、`0–20%` 使用红色。
- 平台品牌色只负责识别，不能覆盖健康、风险、错误等状态语义。
- 余额使用冰蓝；普通消费数字使用主文字色；缓存提示使用蓝灰。
- 使用统一的系统图标语言，禁止 Emoji、卡通钱包和传统圆形仪表盘。
- 减少「每项数据一张大卡」；优先使用连续数据板、清晰分组、表格和紧凑数据单元。

## 交付边界

图片用于确认材质、层级、组件结构和浅深色关系，不是业务数据来源。图中由生成模型重排或补写的数字、日期、文案和字段不得直接进入生产代码；实现必须继续消费真实 ViewModel，并遵守 fresh/stale/missing、Decimal 金额和凭据隔离规则。

待本批母版确认后，再继续生成信号摘要、AI 辅助分析、GLM/Codex 额度变体、悬浮雷达详情和设置页。
